## Project Overview

The Car Wash Management System (CWMS) is an Oracle Database Programming Capstone Project developed to automate the daily operations of a car wash business.

The project demonstrates Oracle SQL, PL/SQL, database design, normalization, triggers, packages, procedures, functions, auditing, and security.
