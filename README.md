# Project Description

The Car Wash Management System (CWMS) is an Oracle Database Programming Capstone Project designed to automate the daily operations of a car wash business.

The system manages:

- Customer Registration
- Vehicle Registration
- Employee Management
- Service Management
- Service Orders
- Payments
- Audit Logs
- Reports

The project demonstrates Oracle Database concepts including SQL, PL/SQL, Triggers, Packages, Procedures, Functions, Cursors, Exception Handling, Normalization, Views, Sequences, and Security.

---

# Project Objectives

- Design a fully normalized relational database (3NF)
- Implement Oracle SQL objects
- Develop PL/SQL procedures and functions
- Create database triggers
- Implement audit logging
- Enforce business rules
- Generate reports
- Demonstrate Oracle Database programming concepts
